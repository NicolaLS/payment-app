# Blip reviewer notes

Blip is a non-custodial client for an existing Blink wallet. It does not create
accounts, exchange assets, sell cryptocurrency, or hold funds.

Provide reviewers with a dedicated Blink API key that has the `WRITE`
permission Blip requires and a wallet funded only with a small review balance.
The key must be delivered through the store's private review-notes field and
never committed to this repository.
